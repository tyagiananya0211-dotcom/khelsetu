# KhelSetu Project Report
**Problem Statement ID:** SIH26196
**Organization:** AICTE

## Abstract
KhelSetu connects students, institutions, and opportunities through a data-driven score and deterministic AI matching.

## Architecture
- Frontend: React + Vite + Tailwind/Vanilla CSS
- Backend: PHP API
- DB: MySQL (Port 3308)
- AI: External LLM via API for insights

## Implementation Rules Used
- Deterministic logic for scores
- LLM fallback for explanations
