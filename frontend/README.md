# KhelSetu - Connecting the Sports Ecosystem

This project was built for SIH26196.

## Structure
- `frontend/` - React, Vite, Recharts, Lucide. Run with `npm run dev`
- `khelsetu-api/` - PHP backend (put in `htdocs`). Port 3308 for MySQL.

## Database
Import `database.sql` into MySQL at port 3308.
